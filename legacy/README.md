# Original Colab notebook (COGS-319, Fall 2024)

`original_notebook.py` is the code from the original Colab notebook, cell by cell and
unchanged except for the cell separators and the IPython-only lines, which are commented out.
It is kept for reference and is **not** part of the `musegen` package.

The main README ("What changed from the notebook") lists each problem found in this
code and where it is fixed in `src/musegen/`.
